# Notebooks

I keep the primary workflow in scripts so the experiment is reproducible from the terminal. After the first real-data run, I would use this folder for exploratory error analysis and paper-style visualization notebooks.

Recommended first notebook after running:

- Load `results/case_metrics.csv`
- Sort by Dice and area error
- Inspect cases in `results/review_queue.csv`
- Add the most informative qualitative overlays to the README or report
